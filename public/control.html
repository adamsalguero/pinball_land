Kiosk control

Displays

Use 1, 2, or 3 screens. The wall opens a window only for each enabled display, left to right. Changes apply live. Restart kiosk windows if a screen stays stuck.

Theme

Ron turns a party theme on from this iPad. It does not follow the calendar. Halloween and Christmas also play family clips from those media folders.

Wall rotation

On by default. Every TV shares one playlist — logos, amenities, the clock, the live pinboard, videos, and enabled leaderboards. Amenities cycles the 2-story arcade, Outdoor Oasis, and Flexible Event Options. Screens are staggered so they do not change at the same moment.

Manual screens

Used only while rotation is off. Assign each TV yourself.

Present

Pick one screen. The others keep rotating. End it from here, or it drops off after the idle time.

Google Cast: a true Cast receiver on this Windows PC isn't practical. Chrome laptops and Android phones should use Browser share. Optional hardware: plug a Chromecast or Google TV dongle into a spare HDMI input on the TV, cast to that dongle, then switch the TV back to the PC input when you are done.

AirPlay

One tap picks the TV. The receiver stays ready. When an iPhone connects, that screen leaves rotation. It comes back when the mirror ends.

Pinball collection

Leaderboards

Event boards and each enabled machine. Toggle “On the wall” to include it in rotation.

Videos

Upload mp4, m4v, webm, mov, or mkv. Play one screen, the same clip in sync on every screen, or one picture spanned across the wall. Holiday folders join the rotation while that theme is on.

YouTube

Only links you paste play. The wall uses the privacy embed, hides controls, and skips videos that cannot be embedded.

Live pinboard

Guests post from the Pinball Land app with no PIN. Approve them here unless auto-approve is on.

Smart plugs

Kasa plugs on the TV power cords only. Set each BenQ Switch on state to On. Never put the PC on a plug.

Transitions

A short crossfade between cards, or off. Screens change a few seconds apart.
